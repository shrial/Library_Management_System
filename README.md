This project is made with the help of Python and MySQL. Python has been used to work with user interface while MySQL has been used to work with databases and tables and a connection between python and MySQL has been 
maintained. 
This Library management system program makes it easier to insert, update and delete data and records. It also helps store data in an organised form. Several tables have been created to store different data 
to help make it accessible easily. 

There are three tables in  the database namely books, issue and submit. The books table contains the list of the books present in the library. The issue table contains the name of the issuer and 
the book. It stores data  regarding issuing of books. The submit table contains the name of the person submitting the book and book details. 

The main program requires the user to enter certain details and provide data which will be stored in the tables present in the databases.  
The user is provided with 5 choices and is asked to choose one of them. Every choice either requires the user to enter certain data or it performs a particular function. 

1. Add a book : 
The user is requested  to add a certain book with the number of copies. this is used to 
add books to the library.

2. Issue a book :  
The user is requested to enter the issuers name and the book they have issued by entering 
the book code.

3. Submit a book that has already been issued : 
This asks the user to enter their name and the code of the book that they had previously 
issued. 

4. Delete books: 
This helps the user to delete existing books from the library. The user has to enter the 
book code and the corresponding book will get deleted from the table containing the list 
of books in the library.

5. Display books in the library : 
This shows the existing books and their copies in the library along with the subject.
